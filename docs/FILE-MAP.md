## Installed Streamrip folder shown in the screenshot

For this uv installation, the package folder is:

```text
~/.local/share/uv/tools/streamrip/lib/python3.13/site-packages/streamrip/
```

The Python version may differ on another machine. The screenshot shows this package-level layout (the `__pycache__/` directory is generated by Python):

```text
streamrip/
├── utils/
├── __pycache__/             # generated bytecode cache; do not edit
├── client/
├── rip/
├── media/
│   ├── album.py             # changed by this patcher
│   ├── playlist.py          # changed by this patcher
│   └── track.py             # local NonStreamableError customization; preserved
├── metadata/
│   └── track.py             # local ISRC/filename customization; preserved
├── console.py
├── __init__.py              # changed by this patcher
├── filepath_utils.py
├── exceptions.py
├── progress.py
├── config.toml
├── db.py
├── converter.py
└── config.py
```

The `media/` and `metadata/` directories contain additional files not expanded in this overview. For upstream originals of the visible files and folders, see [Original upstream file links](UPSTREAM-FILES.md).

## File responsibilities in this repository

- `README.md` — project overview, scope, quick start, and links to detailed documentation.
- `docs/INSTALLATION.md` — package-path identification, dry run, application, batch-size configuration, and rollback.
- `docs/PATCH-REFERENCE.md` — target files, original behavior, modified behavior, rationale, direct target links, and compatibility boundaries.
- `docs/UPSTREAM-FILES.md` — direct links to the original upstream files and folders corresponding to the screenshot.
- `docs/TESTING.md` — transformation tests, smoke tests, and a controlled live-download test plan.
- `docs/CHANGELOG.md` — user-visible changes and known limitations.
- `scripts/patch_streamrip.py` — guarded patcher for the installed Streamrip package.
- `tests/test_patch_streamrip.py` — tests for the patch transformations and their idempotency.
