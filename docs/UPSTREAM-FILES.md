## Notes about these links

The links point to the current `dev` branch, not a version-pinned release or an exact snapshot of the files that were installed on your computer. Upstream can change after this page is written. For an exact rollback copy of your own installation, use the backups made before replacing the installed files.

The files in this repository contain the listed local changes. They are not meant to replace the entire upstream Streamrip package.
